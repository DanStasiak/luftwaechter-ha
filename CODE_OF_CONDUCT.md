# Code of conduct

Be kind, be patient, assume good intent. This is a small hobby project run by volunteers.

- Be respectful. No harassment, insults or discrimination.
- Give specific, constructive feedback. Thank people who help.
- Keep issues on topic. English or German is fine.
- No spam or advertising.

Unacceptable behaviour can be reported privately through GitHub (Security → Report a vulnerability) or by contacting the maintainer, Dan Stasiak. Comments or contributions that break these rules may be removed.
