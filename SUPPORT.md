# Getting help

| I want to... | Go here |
| --- | --- |
| Set it up or fix "no rooms" | [README: Troubleshooting](README.md#troubleshooting) and the Repairs hint in Home Assistant |
| Report a bug | [New bug report](https://github.com/DanStasiak/luftwaechter-ha/issues/new/choose). Attach the diagnostics file: Settings → Devices & services → Luftwächter → ⋮ → *Download diagnostics* |
| Ask for a feature | [Feature request](https://github.com/DanStasiak/luftwaechter-ha/issues/new/choose) |
| Use the Windows widget | [airguard-widget](https://github.com/DanStasiak/airguard-widget) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md) |

Please remove personal data (addresses, tokens) from anything you post.

---

**Deutsch:** Einrichtung und Fehlersuche stehen in der [README](README.de.md). Fehler bitte als Issue melden und die Diagnosedatei anhängen (Einstellungen → Geräte & Dienste → Luftwächter → ⋮ → *Diagnose herunterladen*).
